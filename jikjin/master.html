GitHub 연결 (기획전 입력 저장)

기획전 입력을 모든 기기에서 같이 보려면 GitHub 토큰이 필요합니다. 토큰이 없으면 입력한 내용은 이 기기(브라우저)에만 남고, 엑셀 내려받기는 그대로 됩니다.
토큰은 이 기기에만 저장되며 직진 재고·출고 대시보드에서 이미 연결했다면 같은 토큰을 그대로 씁니다.

새 기획전

표 오른쪽 끝에 노란 기획전 열이 붙어서(표를 옆으로 넘겨도 계속 보임) 품목마다 10%, 5% 처럼 원하는 내용을 직접 적을 수 있습니다. 무엇이든 적은 품목이 참여 상품이 되고, 칸을 비우면 참여에서 빠집니다. 적은 내용은 저장하면 모든 기기에서 같이 보이고, "참여 상품 엑셀"로 플랫폼 상품코드와 함께 내려받을 수 있습니다.
